# 🏠 Real Estate & Agent Finder

A web-based real estate management platform developed as a **university group project**.

The system is designed to help users explore real estate properties, find agents, and manage property-related information through a centralized platform.

> **Academic Project — 2025**  
> Developed collaboratively as part of a university software engineering project.

---

## 📌 Overview

The **Real Estate & Agent Finder** is a Java-based application that provides a platform for managing and exploring real estate properties and agents.

The project focuses on providing users with an organized way to search for properties and access real estate-related information through a centralized application.

---

## ✨ Features

- 🏠 Property management
- 🔎 Property searching and filtering
- 👤 Real estate agent management
- 📋 Property and agent information management
- 🖥️ User-friendly interface
- 💾 Data management
- 🔐 User and system management functionality

🚀 Getting Started
Prerequisites

Make sure you have:

Java JDK
Git
Maven (optional if using the Maven Wrapper)
Clone the Repository
git clone https://github.com/niduwara-j/Real-Estate-and-Agent-Finder.git
cd Real-Estate-and-Agent-Finder
Run the Application

Using Maven Wrapper:

./mvnw spring-boot:run

On Windows:

mvnw.cmd spring-boot:run
